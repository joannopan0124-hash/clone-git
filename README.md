# AI 英语学习助手 - 产品展示PPT

这是一个精美的产品展示页面，介绍了两个英语学习智能体：
- 少儿英语智能体
- 口译训练智能体

## 在线访问

访问地址：https://your-app.vercel.app

## 部署说明

### 方式一：Vercel 部署（推荐）

1. 将代码推送到 GitHub 仓库
2. 访问 [vercel.com](https://vercel.com)
3. 使用 GitHub 账号登录
4. 点击 "Import Project"
5. 选择您的 GitHub 仓库
6. 点击 "Deploy"

### 方式二：本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
